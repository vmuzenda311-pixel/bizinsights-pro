# BizInsights Pro

### Business Intelligence & Analytics Dashboard

BizInsights Pro is a retail business analytics dashboard built with HTML, CSS, JavaScript, and Chart.js. It transforms fictional sales data into interactive performance metrics and visual reports.

## Project Goals

- Analyse revenue and gross profit.
- Track monthly sales performance.
- Compare products and product categories.
- Present business performance through interactive visualizations.
- Demonstrate practical data analytics and dashboard development skills.

## Features

- **Overview:** Executive summary of business performance.
- **Sales Analysis:** Revenue trends, monthly comparisons, and category analysis.
- **Product Performance:** Product rankings, sales volume, and profitability analysis.
- **Interactive filters:** Explore available data by reporting month and category.
- **Responsive design:** Dashboard layout adapts to different screen sizes.

Additional features such as data editing, CSV exports, expense analysis, and revenue targets should be listed here once verified in the application.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- LocalStorage, where persistence is implemented

## Getting Started

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Open `index.html`.
5. Right-click the editor and select **Open with Live Server**.

An internet connection may be required to load Chart.js from its CDN.

## Analytical Methods

The dashboard uses financial calculations including:

- Revenue = Units Sold × Selling Price per Unit
- Cost of Goods Sold = Units Sold × Unit Cost
- Gross Profit = Revenue − Cost of Goods Sold
- Gross Profit Margin = Gross Profit ÷ Revenue × 100

Other calculations depend on the metrics implemented in the application.

## Dataset

The project uses fictional retail data for demonstration purposes. It must not be interpreted as actual company performance.
